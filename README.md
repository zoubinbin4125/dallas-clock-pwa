# 达拉斯时间

手机版 PWA，对应 Mac 桌面应用「达拉斯时间」（Dallas Clock 2.2.0）的上班 / 下班倒计时。

在浏览器打开后，可添加到三星手机主屏幕，离线也能继续看时间和倒计时。浏览器里的页面只能变成图标，主屏幕上看不到走动的倒计时。要在主屏幕放小组件，安装同仓库里的 Android 应用，见文末「Android 主屏幕小组件」。

## 规则

- 时区：America/Chicago（达拉斯，自动 CST / CDT）
- 工作时间：周一至周五 08:30–17:30（达拉斯当地时间）
- 上班前倒计时到 08:30，上班中倒计时到 17:30，下班后或周末倒计时到下一个周一至周五 08:30
- 显示美国 11 个联邦假日及周末调休日（周六调到周五，周日调到周一）
- 联邦假日只作日历标注，不自动当成公司放假（与 Mac 版一致；感恩节次日也不是联邦假日）
- 不含华盛顿就职日、德州独有假日或临时行政休假

假日来源：[OPM federal holidays](https://www.opm.gov/policy-data-oversight/pay-leave/federal-holidays/)

## 本地检查

```sh
node tests/clock-core.test.mjs
node tests/export-fixtures.mjs --check
```

`export-fixtures.mjs` 把 `clock.js` 的结果写成 Android 单元测试夹具。改了 `clock.js` 之后要重新导出，并让 `android/` 里的 Kotlin 移植跟到同一结果：

```sh
node tests/export-fixtures.mjs
cd android && ./gradlew :app:test
```

## 添加到三星主屏幕

用 Samsung Internet 或 Chrome 打开本页 HTTPS 地址。

**Samsung Internet**

1. 打开页面
2. 点底栏或右上角菜单（三条线或三个点）
3. 选「添加页面到」→「主屏幕」，或直接选「安装应用」
4. 把名称保留为「达拉斯时间」，点「添加」

**Chrome**

1. 打开页面
2. 点右上角三个点
3. 选「安装应用」或「添加到主屏幕」
4. 确认安装

## Android 主屏幕小组件

网页版只能固定成图标。这个目录下的 Android 应用会在桌面放真正的小组件，名字是「达拉斯时间」，点一下打开全屏时钟。倒计时规则与上面的网页版、Mac 版 2.2.0 相同，不联网、不登录、不收集数据。

安装包：`dist/dallas-clock-release.apk`  
SHA-256：`adb6077e2d38623c00104aed28c6c0bf736a1bc1470091d0cb66ed16a9029701`  
包名：`com.binbin.dallasclock`  
应用名：达拉斯时间  
系统要求：Android 12 及以上（Galaxy Z Fold 系列的封面屏和内屏都可以）

小组件在列表里有两个，名字都是「达拉斯时间」，看预览和说明区分：

| 小组件 | 默认格子 | 适合 |
| --- | --- | --- |
| 小尺寸 | 3×2 | Z Fold 封面屏。达拉斯时间、状态、倒计时；空间够会显示下一个假日 |
| 宽尺寸 | 4×3 | 内屏。再加上日期和「距上班 / 距下班 N小时NN分」 |

两个都可以横竖拖动。拉宽到大约 250dp 以后，会换成宽布局。

### 传到三星手机并安装

1. 把 `dist/dallas-clock-release.apk` 拷到手机（数据线、网盘，或用浏览器打开仓库里的这个文件下载）。
2. 打开系统设置，允许「未知来源」安装。One UI 常见路径：
   - 设置 → 安全和隐私 → 更多安全设置 → 安装未知应用
   - 或：设置 → 应用程序 → 右上角菜单 → 特殊访问 → 安装未知应用
3. 给「我的文件」或用来打开 APK 的浏览器打开「允许来自此来源」。
4. 在「我的文件」里点这个 APK，安装。应用名应显示为「达拉斯时间」。
5. 若系统询问「闹钟和提醒」或精确闹钟，选允许。小组件靠它在亮屏时大约每分钟刷新一次。

覆盖安装必须用同一把签名。密钥在 `android/keystore/dallas-clock-release.jks`，密码在 `android/keystore.properties`。这是个人旁加载密钥，不是应用商店上传密钥；仓库是公开的话，任何人都可能打出可覆盖安装的包，不要用来装敏感数据。

### 加到封面屏

1. 合上手机，停在封面屏主屏幕。
2. 长按空白处，点「小组件」。
3. 找到「达拉斯时间」，添加说明里带「封面屏」的小尺寸。
4. 拖到合适的位置。封面屏比较窄，优先用小尺寸；可以再稍微拉宽。

如果列表里没有：确认装的是这个 APK，而不是只把网页「添加到主屏幕」。部分 One UI 要到 **设置 → 封面屏幕 → 小组件** 里添加。加完仍是空白的话，重启一次手机。

### 加到内屏

1. 展开手机，在内屏主屏幕长按空白处。
2. 点「小组件」，找到「达拉斯时间」。
3. 添加说明里带「内屏」的宽尺寸。
4. 拖动边缘调整大小。变宽后会多显示日期和下一个联邦假日。

点小组件任意位置会打开应用里的全屏时钟，版式和这页网页一致（封面屏是上下排，内屏够宽时是三列）。

### 刷新和电量

- 倒计时的大数字是桌面里的计时器，亮屏时每秒走。它对准下一次 08:30 或 17:30，过夜也不需要一直唤醒手机。
- 达拉斯钟面、状态（即将上班 / 正在上班 / 已下班 / 周末）和中文「N小时NN分」大约每分钟刷新一次，且只在手机醒着时刷新，不会为了小组件每分钟把手机叫醒。
- 系统自带的小组件轮询最快 30 分钟，应用另外用闹钟补到大约 1 分钟。亮屏或解锁后如果钟面还是旧的，等一两秒。
- 若三星把应用收成「深度休眠」，刷新会停。设置 → 电池 → 后台使用限制 → 达拉斯时间 → 不受限制。
- 全屏页面才保证每秒重画全部文字。联邦假日只作标注，当天如果是周一到周五，倒计时照常走。

### 重新打包

需要 JDK 17+、Android SDK 35 和 Build-Tools 35。

```sh
export ANDROID_HOME="$HOME/android-sdk"   # 含 platforms/android-35 与 build-tools/35.0.0
cd android
./gradlew :app:test :app:assembleRelease
```

签名过的 APK 在 `android/app/build/outputs/apk/release/app-release.apk`。可以把它复制成 `dist/dallas-clock-release.apk`。签名配置已经读 `android/keystore.properties`，不用再填密码。
